# NOPE CHALLENGE — GitHub Pages website (V3)

This package includes the ORIGINAL user-provided NOPE CHALLENGE white and black logos, and original gameplay screenshots. All assets are stored locally inside `assets/` — there are no image dependencies on Squarespace.

## Quick start

1. Extract ZIP contents.
2. Open `index.html` to preview.
3. Create a GitHub repository, upload the CONTENTS of the `nopechallenge-redesign` folder to the repository root.
4. GitHub Settings → Pages → Deploy from branch → main → /(root).
5. Test all pages and links under the free `github.io` address.
6. To move `nopechallenge.com`, configure your domain in GitHub Pages and add the appropriate DNS records with your domain registrar. Create a `CNAME` file containing `www.nopechallenge.com` only if you intend to use the www address as your primary domain. Follow GitHub's current documentation for apex and www setup; protect existing email records.
7. Only cancel Squarespace hosting after the new site is verified on the custom domain. Keep separate domain registration and email services active as needed.

## Copy

The homepage is adapted from the NOPE CHALLENGE Meta store copy supplied by the owner. Nine original VR challenges (Clowns, Heights, Spiders × 3) plus Reality Breach (mixed reality) = ten challenges. Safety messaging is included at the bottom.

## Notes before launch

- Confirm the Meta Quest purchase link, news details, press email, Discord, social links, and any trademark and release data are accurate and still current.
- Homepage screenshot gallery and press area can be expanded with original full-resolution assets. Current news posts are selective summaries and not a full imported archive.
- Pages are static, do not need Squarespace or a paid platform, and can be maintained by editing HTML/CSS/JS.
- Images supplied by the game owner have been converted to web-friendly WebP for faster loading; the source PNG logos are retained unchanged.
